# user-rules.md
Guidelines for operating PolyNote as a power user.

1. Prefer local AI first. Enable Ollama/GPT4All for summaries/translations. Keep models small (3B–7B) unless you have >16GB RAM.
2. Set per‑connector filters to avoid syncing trash/archives.
3. Define a home canonical store (e.g., Obsidian) and mirror out to others; reduces conflicts.
4. Use rule presets: #blog → Notion DB, #private → local only (encrypted), #share → generate `.polynote-share.zip`.
5. Back up `~/.polynote` and vaults with versioned snapshots weekly.
6. For Apple Notes, run macOS app and grant Accessibility permissions for AppleScript access.
7. Prefer Markdown‑first content. For complex embeds, attach original files to preserve fidelity.
